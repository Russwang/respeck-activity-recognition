# 代码与模型导览

这是一个在课程提供的 Flutter 数据采集 App 上扩展的可穿戴动作识别项目。RESpeck 采集胸部三轴加速度，通过 BLE 传到安卓手机，两个本地 TFLite 模型分别识别身体动作及呼吸、咳嗽等信号。模型不读取声音或视频，摄像头只用于设备二维码配对。

## 阅读顺序

| 文件 | 职责 |
| --- | --- |
| [main.dart](../pdiot_har_example/lib/main.dart) | 读取配对信息、版本与存储目录，启动界面 |

| [window_classifier.dart](../pdiot_har_example/lib/services/window_classifier.dart) | 加载配置与模型、检查张量规格、维护窗口和推理 |

## 从数据到预测

一个 BLE 包从第 8 字节起，每 6 字节解出一组 x/y/z；每个样本进入两个模型的滑动窗口。两个窗口都保留最新 120 点，整个包处理完后运行一次推理。只在开启录制时向 CSV 追加数据，录制与识别相互独立。

每个轴在窗口内减去均值，除以总体标准差加 `1e-6`；再附加三个轴的原始均值，并在所有时间点重复。输入为 `[1,120,6]`，通道顺序：

```text
标准化 x、标准化 y、标准化 z、均值 x、均值 y、均值 z
```

身体动作输出 11 类，坐与站合并；信号输出正常呼吸、咳嗽、过度换气、其他，共 4 类。类别顺序从模型旁边的 JSON 清单读取。身体动作分数不高于 0.2 时显示 `Uncertain`，这些区间不计入身体动作时长。分数只是模型输出，不等于实测准确率。

当前使用 `results_physical_cnn_v2` 和 `results_social_cnn_v3` 中的六通道模型，复制到应用的 `assets/physical.tflite` 和 `assets/social.tflite`。模型实际张量、哈希、标签和 CPU 推理均已检查。旧应用里的三通道模型没有可靠的训练版本对应，保留在本地但不再随应用打包。

## 训练流程

[身体动作脚本](../physical_model_leave_n_cv.py) 与 [信号脚本](../social_model_leave_n_cv.py) 从类别子目录读取 CSV，使用 `accelX/accelY/accelZ` 三列，以 120 点窗口、30 点步长切片。共享的 [training_utils.py](../training_utils.py) 实现六通道预处理、命令行参数和导出清单。

身体动作 CNN 为两组卷积与池化，之后 Flatten、Dense(64)、Dropout(0.3)、softmax。信号 CNN 为三组卷积、BatchNorm 与池化，之后全局平均池化、Dense(64)、Dropout(0.25)、softmax。两者都使用类别权重。

身体动作默认 5 折，信号默认 3 折，按录制文件做 GroupKFold。同一文件的窗口不会跨外层训练和测试集，但同一参与者的不同文件可能跨组；不能当作跨参与者验证。信号脚本内部的验证拆分也不是按参与者或文件分组。

命令示例和环境配置见 [项目首页](../README.md)。训练输出默认写到 `training_outputs/`，非空输出目录会拒绝覆盖；找不到数据或某类没有有效窗口会给出明确错误。

## 历史统计与录制

预测类别与浮动分数已经分开，历史以 `Activity: 类别` / `Signal: 类别` 为键。相邻包之间的时间归给上一条有效预测，使用毫秒累计，跨午夜分到不同日期。断连、应用离开前台会重置会话，超过 5 秒的无数据间隔不进行推算。历史每 5 秒及会话结束时尝试保存，强制终止可能丢失尚未保存的最近数据。

旧版本 `history` 键内的计时存在错误，因此保留原数据，但不自动合并到新的 `history_v2_ms` 统计中。

录制 CSV 包含手机时间、传感器时间、包/样本序号与三轴加速度；手选标签放在文件名。训练脚本则从目录名取标签；原始“录制文件 → 清洗/合并类别 → 训练目录”的整理脚本尚未找到。

## 修复、证据与边界

本轮已修复模型接口不一致、类别映射、历史空值/丢时长、未找到蓝牙设备时空值崩溃、异常包越界、二维码取消返回空值、两模型释放、页面异步更新检查等问题，并替换模板测试。

历史身体动作评估平均准确率 90.53%，信号评估 70.21%；这是结果文件已有数据。模型文件、映射和现有脚本相互一致，不代表已经恢复完整训练溯源：仍缺原始数据、原训练日志及最终报告，不能宣称本轮重现了这些指标。

课程大纲要求的 12 种动作和 6 种社交信号，比当前 11 类动作 / 4 类信号范围更广。当前信号识别也没有限制为仅在静态姿态时运行。具体差异见 [课程背景与范围](COURSE_CONTEXT.md)。

完整验证、缺失项和后续事项见 [项目状态](PROJECT_STATUS.md)；模型契约及替换步骤见 [模型说明](MODELS.md)。
