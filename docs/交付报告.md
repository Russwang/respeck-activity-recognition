## 已修复

- **模型接口不一致**：采用结果目录里附带标签映射的两个六通道模型，统一 120 点窗口与预处理；增加模型规格和类型检查。
- **标签映射**：从与模型一起保存的映射生成配置，不再沿用旧模型硬编码顺序。
- **历史统计**：类别与置信度分离，修复空值崩溃和亚秒计时丢失，处理类别切换、跨午夜、断连和长时间无数据；旧历史数据独立保留。
- **蓝牙及页面健壮性**：检查未发现设备、异常数据包、二维码取消、文件写入失败和页面销毁后的异步回调；释放两个模型资源。
- **工程复现**：修正 Python 依赖和安卓 Gradle/Java 版本；训练脚本支持命令行路径、随机种子、明确的缺数据错误、导出配置及防覆盖检查。
- **测试和展示**：替换 Flutter 模板测试，加入回归测试、模型验证、合成数据训练检查和 GitHub 自动构建。

5. **本地 Android SDK 与实物设备验证**：仍需安卓手机和 RESpeck 测试连接、录制、预测和长时间运行。
6. **性能实测与展示截图**：目前没有可验证的端侧延迟、功耗、内存数据，以及新版应用现场截图。
